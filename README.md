# Fernhall homepage prototypes

Two static homepage prototypes for a fictional savings app, "Fernhall", built for a design research study.

- `/version-a/`
- `/version-b/`

## About this study

These pages are stimulus material for an unmoderated online design study. Participants are shown one homepage and asked about their impressions of it. The two versions share the same brand, product and page structure and differ in design.

Fernhall is not a real company or product. There is no real service behind the pages, and nothing on them should be relied on: the figures, testimonials, prices and security claims are invented for the study. Do not enter any personal or financial information; there is nowhere to submit it.

The study's questions and findings are not published here. If you have come across these pages and want to know more, contact the repository owners.

## Notes on the prototypes

- Every link and button is inert.
- Each folder is self-contained plain HTML and CSS, with one exception: both pages load a script from Useberry, the survey tool used to run the study, which records how participants interact with the page during their session.
- Every page carries `noindex` so search engines are asked to skip it.
