# Fernhall homepage prototypes

Two static homepage prototypes for a fictional savings app, "Fernhall". Every link and button is inert.

- `/version-a/`
- `/version-b/`

Each folder is self-contained plain HTML and CSS (no JavaScript, no external requests) and carries `noindex`.
